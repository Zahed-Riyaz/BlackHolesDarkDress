# BlackHolesDarkDress_Data

N-body simulation results, associated with the [BlackHolesDarkDress repository](https://github.com/bradkav/BlackHolesDarkDress).  

Each `.tar.gz` archive contains snapshots for a particular simulations run. 

The files should be named along the lines of `M30_a0.01_lo_single` for a 30 solar mass PBH, with a semi-major axis a = 0.01 pc and low resolution simulations. In this case, `single` denotes that only a single PBH+Halo is simulated. Binary simulations are named like `M30_a0.01_lo_bin_e0.995` where e = 0.995 is the eccentricity of the orbit. The high-resolution version would be named `M30_a0.01_hi_bin_e0.995`. Finally, some simulations have `_full` at the end, which indicates that they start at periapsis (not part way through the first infall).
